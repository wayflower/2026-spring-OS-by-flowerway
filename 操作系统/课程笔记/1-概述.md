# 1-操作系统概述 (Principles of Operating System)

## 一、 操作系统是什么？(定义与目标)

- **基本定义**：操作系统是计算机系统中的一个系统软件，是一些程序模块的集合。
- **核心作用**：
    - **资源的管理者**：以有效、合理的方式组织和管理计算机的软硬件资源。
    - **服务的提供者**：合理组织工作流程，控制程序执行，向用户提供灵活方便的服务。
    - **机器能力的扩展**：将物理资源（如CPU、内存、磁盘）转换为更通用、更强大的虚拟形式（虚拟机），易于扩展。
- **设计与实现目标**：抽象、模块化、高性能（最小化时间/空间开销）、提供保护（隔离与安全）、可靠性、节能以及移动性。

## 二、 认知操作系统的三个视角

1. **资源管理的观点 (自底向上)**：
    - 操作系统是硬件资源（CPU、内存、I/O设备）和软件资源（文件、信息）的管理者。
    - **目的**：通过时间及空间两种方式实现资源的复用（共享），提高利用率。
    - **手段**：使用数据结构和算法跟踪资源状态，并采用动态或静态策略分配和回收资源。
2. **进程的观点 (动态观察)**：
    - 操作系统是由一些可同时、独立运行的进程，以及一个对这些进程进行协调的核心组成的。
3. **虚机器观点 (自顶向下/内部结构)**：
    - 操作系统分为若干层，每层完成特定功能构成虚机器，向用户提供接口（APIs/标准库）完成请求。

## 三、 操作系统的四大基本特征

1. **并发 (Concurrency)**：处理多个同时性活动的能力。宏观上多个程序同时执行，微观上（单CPU）轮流执行。
2. **共享 (Sharing)**：操作系统与多个用户程序共同交替使用有限的系统资源。分为互斥共享（如打印机）和同时共享（如可重入代码、磁盘文件）。
3. **虚拟 (Virtual)**：将一个物理实体映射为若干个逻辑实体（分时或分空间），如虚处理器、虚拟内存地址空间。
4. **随机性/不确定性 (Randomness)**：必须随时响应以不可预测的次序发生的事件，进程走走停停的速度不可预知。

## 四、 核心技术：SPOOLing (假脱机技术)

- **全称**：Simultaneous Peripheral Operation On-Line (同时的外围设备联机操作)。
- **工作原理**：利用磁盘作缓冲，在输入井和输出井中传递数据，将输入、计算、输出组织成独立的任务流，使I/O和计算真正并行。
- **主要特点**：
    1. 提高了I/O速度，缓和了CPU与低速I/O设备速度不匹配的矛盾。
    2. 将独占设备改造为共享设备。
    3. 实现了虚拟设备功能（每个进程都认为自己独占该设备）。

## 五、 操作系统的发展历程与分类

- **发展阶段**：经历了大型机 -> PC机 -> 网络 -> 移动计算 -> 云计算 -> 物联网 -> 人机物融合（泛在操作系统）。
- **主要分类**：
    1. **批处理操作系统**：分为单道和多道批处理。作业自动组成作业流依次执行。缺点是缺乏交互。
    2. **分时操作系统 (Time-sharing)**：将CPU时间划分成时间片轮流服务终端用户，利用人的错觉实现同时在线工作，追求及时响应。第一款分时系统是 CTSS。
    3. **实时操作系统 (Real-time)**：能在规定的严格时间内处理事件，关键参数是时间，追求高可靠性。分为硬实时（绝对按时完成）和软实时（偶尔可超限）。
    4. **其他**：网络操作系统、分布式操作系统（特征为处理分布、统一OS、透明性、自治性）、嵌入式操作系统以及智能卡操作系统。

## 六、 著名操作系统历史案例

- **失败与教训**：IBM的OS/360（引发《人月神话》思考）和 MULTICS 系统早期因过于复杂而进度严重受挫 。
- **成功典范**：1969年，Ken Thompson 和 Dennis Ritchie（图灵奖获得者）在贝尔实验室为了玩星际探险游戏，在一台闲置的 PDP-7 计算机上开发出了 UNIX 操作系统。
